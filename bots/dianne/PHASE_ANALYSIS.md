# 三阶段拆分与拍卖模块对照

2026-11-09，基于首版提交 `7e99a53`，约开赛后第 23 分钟完成。

推荐采用翻牌前下注、拍卖、翻牌后下注三个接口，并固定其中两个模块来
比较第三个。评价指标仍用完整牌桌的名次积分，保留三个阶段之间的影响。

## 当前领先策略

此前 4,096 桌固定阵容结果如下。

| 方案 | 均分 | 整体逻辑 |
|---|---:|---|
| ICM v2 / selected | 14.580 | 位置和牌力控制入池，泡沫期提高冒险门槛，大额单挑跟注比较 ICM，短筹码时调整侵略性 |
| 原 ICM | 13.772 | 同一路线，尚未包含可争夺底池、超额全押退款及弱同花／葫芦修正 |
| Push/fold | 12.827 | 约 14BB 以下偏向推／弃，深筹码小额开池，低 SPR 强牌全押，以折叠概率和简洁决策获取收益 |

ICM 的拍卖模块枚举十种翻牌，按相对免费默认翻牌的改善选择组合。
预算随底池重要程度、剩余筹码、预计未来机会和全押风险调整，在三个
目标牌上分配出价。它使用启发式牌力和风险溢价，未连接 Fullhouse 神经网络。
单挑大额跟注使用精确前三名 ICM；其他下注判断包含近似。

Push/fold 拍卖更偏向当前生存价值，按目标牌的边际贡献分配出价，在短筹码
和全押时加速消耗预算。

## 控制实验

五个版本的翻牌前、翻牌后下注代码完全一致，均为 selected。仅替换
拍卖函数。逐一面对相同七个固定对手，用相同牌局种子和完整座位轮换。
每个版本 512 桌，共 64 个独立 block。检查确认所有版本的对手座位完全
一致。这里的对手阵容与之前 4,096 桌不同，分数须在本表内比较。

| 拍卖模块 | 平均名次积分 | 相对原拍卖的配对差 | 普通 95% 区间 |
|---|---:|---:|---|
| 原 ICM 拍卖 | 17.871 | 0 | — |
| 全程零出价 | 11.074 | -6.797 | [-8.607, -4.986] |
| 机会成本／预测价格 | 13.477 | -4.395 | [-6.095, -2.694] |
| Push/fold 的拍卖模块 | 16.523 | -1.348 | [-3.252, 0.557] |
| 原拍卖出价翻倍，受余额上限约束 | 18.145 | +0.273 | [-0.573, 1.120] |

五个版本全部零非法动作／异常。这是直接调用官方引擎的强度比较，耗时
另行记录，评分时不执行超时。区间以完整 block 的配对差计算，采用正态
近似，未做多重比较校正。

原拍卖相对零出价的收益在当前场次中明显。更复杂的机会成本模型表现更差。
翻倍出价的改善尚无法与采样波动区分，当前交付仍采用原拍卖。

源文件生成脚本为 `tools/phase_ablation.py`，它从首版冻结候选提取函数，
断言下注 Agent 类保持同样的语法树。生成文件位于忽略的
`.runtime/boston/phase-ablation-candidates/`。源码哈希、原始逐桌结果及汇总
保存在 `results/ablation-phase_*` 和 `results/phase-ablation-summary.json`。

## 隐藏出价的信息边界

本轮拍卖结束前，公开余额不反映本轮任何人的出价。结算后，某人余额减少
20，只能确定他在三张入选牌上的出价总和是 20。分配可能是 (20, 0, 0)、
(7, 7, 6)，也可能是其他组合。两张未入选牌上的出价完全不计费，因此也
无法从余额变化中读出。

机会成本策略中的逐牌预测是根据牌面和公开剩余余额构造的粗略先验。
它并未读到对手本轮的真实出价。当前数据也不足以将其先验视为校准过的
价格模型。`opponent_adaptive` 只统计公开总支出与下注事件。

进一步优化可对潜在出价分配建概率模型，用入选集合、公开总支出、历史
下注和摊牌更新。只有总额约束时，应保留多种可能分配。

## 阶段之间需要传递的状态

1. 翻牌前需要知道自己与对手的拍卖余额。控制翻牌的能力会改变边缘手牌
   的入池价值，影响能否在后续拿到有利牌面。
2. 拍卖应评价后续下注策略下的预期名次收益，并考虑未来预算价值。公共牌
   同时改善其他玩家，单看自身牌型提升可能高估一次出价的收益。
3. 翻牌后需要处理拍卖淘汰的两张已知死牌，以及被竞价筛选后的牌面分布。
   传统 Hold'em 模型的牌面和对手范围假设需要重新校准。

仓库中的 Fullhouse 研究基于标准六人 Hold'em 和筹码收益。接入 Boston
还需要官方动作适配、八人／ICM处理、死牌支持和完整路径延迟验证。
目前已完成的是规则下注策略与拍卖模块的组合实验，Fullhouse 模型加
Boston 拍卖的成绩仍待验证。
